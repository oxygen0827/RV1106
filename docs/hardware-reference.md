# Echo-Mate 硬件参考

## 核心参数

| 项目 | 已知值 | 说明 |
| --- | --- | --- |
| SoC | Rockchip RV1106 系列 | 单核 32-bit Cortex-A7，NEON/FPU |
| 内存 | 256 MB DDR3L | 项目页面与仓库一致 |
| NPU | 目标资料标注 1 TOPS | 文档版本曾从 0.5 修正为 1 TOPS；必须核对顶标并实测 |
| 显示 | P024C128-CTP，240x320 | 2.4 英寸、4-wire SPI、ST7789V3 |
| 触摸 | FT6336U | I2C 电容触摸 |
| Wi-Fi/BT | RTL8723BS | Wi-Fi 使用 SDIO；蓝牙支持仍需实机验证 |
| 存储 | SD 卡或 SPI NAND | 默认启动优先级会影响介质选择 |
| 音频 | RV1106 内置 ACodec | 板上喇叭/MIC 为 MX1.25 接口 |
| 摄像头 | SC3336 | 配件表推荐；可先不装，OV2685 仅为后续设想 |
| 扩展 | 8 个 GPIO 引出 | 使用前查原理图/设备树复用 |

旧附件的 RV1106 Datasheet Rev 1.1 写 0.5 TOPS；项目页面写 1 TOPS。2026 年 Datasheet Rev 2.0 明确把 RV1106G2、RV1106G3 和 RV1106 都列为 1.0 TOPS，并把 G2/G3 内存分别列为 1 Gb/2 Gb DDR3L。Echo 的 256 MB 资料因此指向 G3，但模型预算仍应在板上读取顶标并跑基准后确定。

## 屏幕安装

LCD 接口是翻盖式 FPC 连接器：

1. 断电，先掀起连接器锁扣。
2. 确认排线触点方向与座子一致，不要依靠蛮力判断。
3. 将排线平行、均匀地插到底，左右露出长度应一致。
4. 保持排线不后退，再压下锁扣。
5. 锁扣盖不紧时先退出重插；通常是排线停在连接器外沿，并非需要更大压力。

不要带电插拔。锁扣很脆，不能把它当作把排线“压进去”的机构。

## P024C128-CTP 规格

规格书给出的关键参数：

- 分辨率：`240RGB x 320`
- 显示接口：4-wire SPI
- LCD 驱动：ST7789V3
- 触摸驱动：FT6336U
- 显示区：36.72 x 48.96 mm
- 模组外形：42.72 x 60.26 x 3.15 mm
- LCD 供电典型值：2.8 V；数字 I/O 支持范围由板级设计决定
- 背光：4 颗 LED，典型 2.8 V、60 mA，建议恒流驱动

Echo SDK 当前设备树进一步给出软件配置：LCD 在 SPI0、最大 60 MHz、旋转 270 度；背光使用 PWM9；FT6336 在 I2C3 地址 `0x38`、100 kHz、最多 5 点触摸，同样旋转 270 度。这些是当前软件基线，不替代原理图电气确认。

16-pin FPC 定义：

| Pin | 信号 | 功能 |
| --- | --- | --- |
| 1 | GND | 地 |
| 2 | VCC | LCD 供电，规格书标注 2.8 V |
| 3 | SDA | SPI 数据输入/输出 |
| 4 | SCK | SPI 时钟 |
| 5 | CS | LCD 片选 |
| 6 | RESET | LCD 复位 |
| 7 | BL_A | 背光正极 |
| 8 | BL_K | 背光负极 |
| 9 | NC | 未连接 |
| 10 | RS | 数据/命令选择 |
| 11 | CTP_RST | 触摸复位 |
| 12 | CTP_INT | 触摸中断 |
| 13 | CTP_SDA | 触摸 I2C 数据 |
| 14 | CTP_SCL | 触摸 I2C 时钟 |
| 15 | VCC | 触摸/模组供电，以原理图为准 |
| 16 | GND | 地 |

表中电气值用于理解模组，开发时不要绕过板上电源/背光电路直接给 FPC 供电。

## 存储与启动

- 推荐开发初期使用 SD 卡，方便恢复和替换镜像。
- 手册明确：SD 启动时 SPI NAND 必须为空，否则会优先从 NAND 启动。
- 官方 SD 镜像分区参数包含约 6 GB rootfs，建议使用质量可靠的 8-16 GB 卡；手册建议不超过 16 GB。
- NAND 镜像 rootfs 为 UBIFS，SD 镜像 rootfs 为 ext4，不能把两套分区脚本混用。
- 烧录时优先直连电脑 USB，不经扩展坞。

## 音频

RV1106 ACodec 支持 24-bit ADC/DAC、8-96 kHz 常用采样率、MIC 增益、ALC/AGC 和 line-out。Echo 的 AIChat 默认使用 16 kHz、单声道、40 ms 帧并传输 Opus。

需要注意：内部 ACodec 占用 I2S0；使能后外部 I2S0 引脚不能同时作为独立 I2S 使用。音量、MIC 模式和 PA GPIO 以当前设备树及 `amixer` 实际 control 为准。

## 摄像头与图像链路

- 配件表当前推荐 SC3336，连接前核对排线方向和 MIPI CSI lane/电压。
- Echo 设备树的 SC3336 使用 I2C4 地址 `0x30` 和 2-lane MIPI CSI；板级配置同时打包 SC3336/SC4336 IQ 文件。
- 当前 dtsi 把 SC3336、SC4336、SC530AI 三个同为 `0x30` 的节点都标成 `okay`，且共用 CSI/电源控制。实物只能是一种传感器；做稳定固件时应只使能实际型号，避免探测顺序和日志不确定。
- 官方 DeskBot 的 YOLO 路径使用 opencv-mobile 获取画面，接入简单，但没有充分利用 VI/VPSS 硬件链路。
- 追求帧率时再迁移到 Rockchip MPI 的 VI/VPSS；不要在 UI 功能尚未稳定时同时更换摄像头、设备树、采集链路和模型。

## 机械件

官方配件表的关键项：

- 43903 履带 2 条、减速马达 2 个。
- F683ZZ `3x7x3` 轴承 2 个。
- 上下板排线：Z1 方向、2x6 pin、15 cm。
- 屏幕挡板使用 M2x10 尼龙螺丝 4 个。
- 3D 包含上盖、底座、底座盖、屏幕挡板、主动轮和从动轮 STL。

开发软件不依赖履带和外壳；建议先裸板完成屏幕、触摸、网络和应用验收，再装机械结构。
